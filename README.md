# 🍞 El Pan de Cada Día

Sitio web de la panadería artesanal **El Pan de Cada Día** — Torreón, Coahuila.

> *Pan hecho con Pasión · Con el sabor de siempre…*

## 🌐 ¿Qué incluye?

Página web de una sola página (single-page) con las secciones:

- **Inicio / Portada** — Pan hecho con Pasión
- **Beneficios** — Pan fresco todos los días, ingredientes de calidad, hecho con amor
- **Productos / Menú** — Pan de Hamburguesa, Pan Francés, Pan Artesanal y Dulce (precios de mayoreo)
- **Nosotros** — Pan artesanal elaborado cada día
- **Entregas** — Entregas a domicilio a tu negocio
- **Ubicación** — Mapa y dirección
- **Pedidos** — Formulario que arma tu pedido y lo envía por WhatsApp
- **Contacto** — WhatsApp, teléfono y redes sociales

## 🛠️ Tecnología

HTML, CSS y JavaScript puro (sin frameworks). No requiere instalación.

```
index.html          → Estructura del sitio
css/styles.css      → Estilos (paleta café / dorado / crema)
js/main.js          → Menú móvil y formulario de pedidos a WhatsApp
assets/img/         → Imágenes (logo, portada, productos, reparto)
```

## 🚀 Ver el sitio

Puedes abrir `index.html` directamente en el navegador, o publicarlo gratis con **GitHub Pages**:

1. Ve a **Settings → Pages** en este repositorio.
2. En *Source* elige la rama `main` y carpeta `/root`.
3. Guarda y espera 1–2 minutos: tu web quedará en línea.
